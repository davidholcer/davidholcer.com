# Bananagram Tiles

I'm a big fan of bananagrams, so how cool would it be to interact with the tiles like as if you were doing it in real life? Try it out for yourself :)

![[p5js width = 800, height = 800, sketchWidth = 800, sketchHeight =  800]][[bananagram_tiles.js]]

## Controls
- **Click and drag** to push tiles around
- **Shift + Click and drag** to rotate tiles
- **Spacebar** to reset the composition
- **Any letter (A-Z)** to hide/show all tiles with that letter
- **Alt/Option + Click** on a tile to hide/show all tiles with that letter
- **1** to toggle bananagrams (letter) mode
- **`** (backtick) to toggle alphabetical order
- **,** (comma) to toggle letter visibility
- **.** (period) to toggle tile visibility
- **/** (slash) to toggle connection lines
