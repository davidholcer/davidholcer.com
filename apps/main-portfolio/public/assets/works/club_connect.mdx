# ClubConnect Project Overview

ClubConnect is a web-based hub designed to make it easier for McGill students to discover, follow, and engage with extracurricular clubs. The platform integrates a personalized dashboard, club profile pages, posting functionality, and an authentication system to ensure secure and dynamic interaction between students and organizations.

The project was deployed on **Netlify** with a running version available at [my-clubs.netlify.app](https://my-clubs.netlify.app). It was developed collaboratively by a small team of frontend and backend developers, each contributing specific features to ensure both usability and robust functionality.

## Tech Stack

- **Frontend**: React, HTML, CSS, JavaScript  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT (RSA 256 encryption, 48-hour expiry)  
- **Image Handling**: Cloudinary API  
- **Hosting/Deployment**: Netlify (frontend), Node.js server (backend)  

---

## Features

- **User Authentication & Profiles**  
  Students can sign up, log in, and manage their personal profiles securely with JWT tokens.  

- **Club Directory & Search**  
  Explore clubs through a searchable directory, with profile pages displaying events, feeds, and details.  

- **Follow & Dashboard**  
  Follow clubs of interest and see a tailored dashboard feed with posts from those clubs.  

- **Posting System**  
  Clubs can create and manage posts (text and media) for their members and followers.  

- **Media Uploads**  
  Integrated Cloudinary API to handle club logos, banners, and media uploads with automatic optimization.
